# Robots
Проект по изучению концепций OO-дизайна и разработке MDI-приложений на Java

Задача 1.1: Научиться собирать проект с использованием Apache Maven.

	Умение собирать код без среды разработки необходимо для того, чтобы организовать рабочий процесс — 
	код нужно регулярно собирать, проверять что он компилируется, а потом, для того чтобы убедиться в 
	работоспособности кода, прогонять тесты.
	
	Система сборки это программа, которая собирает другие программы. На вход система сборки получает 
	исходный код, а на выход выдаёт программу, которую уже можно запустить. Система сборки вызывает компилятор 
	при своей работе, а компилятор о существовании системы сборки даже не подозревает.(сборка, помимо компиляции, 
	включает в себя ещё целый спектр задач. Например, если программе для работы нужны какие-нибудь картинки, 
	то положить их в директорию с программой — задача системы сборки. Если программе нужны сторонние библиотеки, 
	то положить их в директорию с программой — задача системы сборки.)
	
	В рамках задачи сделано: 
	
		1. Создан файл конфигурации Maven — pom.xml, в нем описаны:

			- Идентификаторы проекта (groupId, artifactId, version)
			- Версия Java для компиляции и запуска (21)
			- Расположение исходного кода (папка src/)
			- Главный класс приложения (gui.RobotsProgram)
			- Плагин для создания исполняемого JAR-файла

		2. Настроена система сборки:
		
			- Проект собирается командой mvn clean compile:
				    clean — удаляет предыдущие результаты сборки
					compile — компилирует исходный код в байт-код (.class файлы)
			
			- Создаётся исполняемый JAR-файл командой mvn package:
					Упаковывает скомпилированные классы в JAR-архив
					Результат: target/Robots-X.X-SNAPSHOT.jar
